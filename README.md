# `wikidot-https-helper`

A tool to find and, ultimately, fix everything that was broken by [Wikidot](https://wikidot.com)'s sudden switch to all-HTTPS on 2026-09-21.

## Usage

This is currently made to be used with a SQLite database generated by [`wikidot-css-extractor`](https://github.com/emmiegit/wikidot-css-extractor).
