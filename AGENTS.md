# Agent instructions

## LLM usage policy

Follow the Rust project's [LLM usage policy]. It applies to all LLM-generated text even if a human later edits it.

[LLM usage policy]: https://forge.rust-lang.org/policies/llm-usage.html

When asked to add a feature or capability, propose an approach (data model, tradeoffs, alternatives) and stop there. Do not write code, or a diff, unless explicitly asked (and even then, remind the user that the aforementioned policy applies).
